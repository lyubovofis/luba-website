# Off-Page & Local Authority Checklist (service businesses)

> On-page (the 423 params) gets you eligible. Off-page gets you chosen. STRATEGY §1.3: "LLMs cite brands that other reputable sites mention" — this file is the operational checklist for that. For local service businesses the local pack + AI answers are won here, not in HTML.

## 1. Google Business Profile (the #1 local asset)

- [ ] GBP claimed + verified for each real office (never fake addresses — suspension risk)
- [ ] Primary category exact (e.g. "Garage door supplier" / "Garage door repair") + all applicable secondary categories
- [ ] NAP (Name, Address, Phone) **byte-identical** to the site footer and schema — this is what `data_consistency` checks on-page; GBP must match it
- [ ] Services list filled with real prices; service area set (SAB: hide address, set radius/cities)
- [ ] Photos: 10+ real job photos, refreshed monthly (geo-tagged where natural)
- [ ] Google Posts: 2-4/month (offers, completed jobs, seasonal tips)
- [ ] Q&A section seeded with the same questions as the site FAQ
- [ ] Website link points to the matching city/service landing page where GBP allows (not always homepage)

## 2. Reviews (velocity + recency beat total count)

- [ ] Steady velocity target: 10-20 new Google reviews/month (ask EVERY completed job — SMS link same day)
- [ ] Respond to 100% of reviews within 48h (owner responses are a ranking + trust signal)
- [ ] Keywords appear naturally in reviews ("spring repair", city names) — ask customers to mention the service performed, never script the text
- [ ] Secondary platforms: a base on Yelp, BBB (listing even without accreditation), HomeStars/Houzz (per niche)
- [ ] Site `aggregateRating` count/score synced with reality (stale counts = `data_consistency` fail + trust risk)
- [ ] NEVER: bought reviews, review gating (filtering unhappy customers before asking), employee reviews

## 3. Citations & directories (NAP everywhere, identical)

- [ ] Tier 1: Google, Bing Places, Apple Business Connect, Yelp, BBB, Facebook
- [ ] Tier 2 (country-specific, e.g. Canada): YellowPages.ca, 411.ca, Houzz, HomeStars, local chamber of commerce
- [ ] Niche directories: manufacturer dealer locators (e.g. LiftMaster/Clopay dealer pages — these are authority backlinks AND citations), trade associations (IDEA, BBB trade categories)
- [ ] Audit existing citations for NAP mismatches after any address/phone change (old NAP lingering = local rank suppressor)

## 4. Backlinks & brand mentions (AI-citation fuel)

- [ ] Manufacturer/partner pages link back (authorized dealer listings)
- [ ] Local press: 1-2 stories/year (seasonal angle: "winter spring failures spike", community sponsorship)
- [ ] Sponsorships: local sports teams, community events — real links from real local sites
- [ ] Reddit/community presence: genuinely answer questions in local + trade subreddits (LLMs heavily weight Reddit)
- [ ] Supplier/partner cross-mentions
- [ ] Track: DataForSEO `backlinks` endpoints (skill: `d4s.py ranked|rank`) + brand-mention share in AI answers (see MEASUREMENT-KPI.md)

## 5. Entity consistency (the knowledge-graph layer)

- [ ] `sameAs` in site schema lists ALL real profiles (GBP map URL, Facebook, Instagram, Yelp, BBB...) — and those profiles link back to the site
- [ ] One canonical brand name spelling everywhere (no "Co."/"Inc." drift between surfaces)
- [ ] Founder/expert person entity: same name + credentials on site (AuthorBio), GBP, LinkedIn — person-level E-E-A-T
- [ ] Wikipedia/Wikidata only if genuinely notable — do not spam

## Cadence

| Task | Frequency |
|---|---|
| Review requests | every completed job |
| Review responses | ≤ 48h |
| GBP posts + photo refresh | 2-4× month |
| Citation NAP audit | quarterly + after any NAP change |
| Local press/sponsorship outreach | quarterly |
| Backlink + AI-mention tracking | monthly (see MEASUREMENT-KPI.md) |
