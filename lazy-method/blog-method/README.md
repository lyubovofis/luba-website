# blog-method/ — Blog post SEO for 2026-2027 (AI-first)

Dedicated parameter set + process for writing blog posts that rank in Google and get cited by AI engines. Separate from the page/service QA (local-service niche) — blogs use the `publisher` niche + these params.

| File | Use |
|------|-----|
| **BLOG-PARAMETERS-2026-2027.md** | The master checklist — 128 params / 11 categories. Audit every post against it. |
| **BLOG-WORKFLOW.md** | The repeatable loop: keyword → competitor/SERP analysis → brief → write → QA → publish → refresh. |
| **BLOG-BRIEF-TEMPLATE.md** | Fill before writing each post. |

**When writing a blog post:** open BLOG-WORKFLOW.md, fill a BLOG-BRIEF, write to BLOG-PARAMETERS, then QA against it + `lazy-check.py` with the `publisher` niche. Related: `../niche-profiles/publisher.json`, `../AUTHOR-BIO-TEMPLATE.md`.
